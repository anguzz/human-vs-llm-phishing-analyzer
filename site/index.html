Class proof of concept, not a security tool.
  • The dataset has both human-written and LLM-generated phishing and legitimate email, but a model trained on it can still learn dataset- or source-specific writing patterns instead of general phishing behavior. The cross-source test above shows it does.
  • The groups come from different eras (human legitimate email from 2007–2008 mailing lists, human phishing from 2019–2022), which may inflate accuracy.
  • Duplicate emails were removed before training (4,000 rows → 3,200 distinct emails).
  • Predictions reflect patterns in this dataset only and should not be treated as a definitive security verdict.
